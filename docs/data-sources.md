# Data sources

## FOCUS / Cost Management exports

Used for:

- Commercial changes versus previous month and quarter.
- Service, meter, resource, subscription, and tenant rankings.
- Effective cost, billed cost, list cost, savings versus PayG.
- Pricing model split such as OnDemand, Reservation, Savings Plan, and Spot.
- Tag-based ownership where tags are available.

## Azure billing and commitment APIs

Used for:

- Reservation coverage and utilization.
- Savings Plan coverage and utilization.
- Expiring commitments.
- Reservation and Savings Plan recommendations.

## Azure Advisor

Used for:

- Right-sizing recommendations.
- Idle resources.
- Cost optimization recommendations.

## Azure Monitor

Used for:

- CPU, RU/s, bandwidth, ExpressRoute, and service-specific utilization.
- Correlation between cost movement and technical usage.

## Activity Log / Resource Graph / Change Analysis

Used for:

- Root-cause candidates behind cost changes.
- SKU changes, scale events, deployment changes, and resource inventory.
